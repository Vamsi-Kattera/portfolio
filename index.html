First published 22 October 2025

AI or Real Image Detector

Can a model tell a real photo from an AI-generated one?

A binary image classifier built with transfer learning: a frozen MobileNetV2 pretrained on ImageNet, a small dense head with dropout, and augmentation (flip, rotation, zoom, contrast and brightness). It reached over 80% classification accuracy. You upload an image and get a label with a confidence score, through a Streamlit app and a small FastAPI endpoint.

Detectors like this generalise poorly to new image generators, so treat the score as a hint.

Python, TensorFlow, Keras, MobileNetV2, Streamlit, FastAPI

Adaptive Coding Practice

A practice app that adjusts to how fast you solve.

A Streamlit app with 50 coding challenges and 50 quiz questions across easy, medium and hard. It runs your function against stored test cases, scores +10 for a correct answer and −5 for a wrong one, and moves you up a level after a correct answer in under 40 seconds (30 for quizzes). After a wrong answer, Gemini writes a hint that does not give the solution away.

Submitted code runs with exec and no sandbox, so this is for local use only.

Python, Streamlit, Gemini API, pandas

An assistant for my own laptop that I can talk to.

Jackey listens offline for its wake word using Picovoice Porcupine, takes a spoken request, answers through Gemini 2.0 Flash and speaks the reply. It keeps a memory file of tasks and recent conversation, opens apps and websites, and reads out the time, date and weather.

AI Traffic Monitoring System

From single images to a system that watches video.

A YOLOv8 detector with ByteTrack follows each vehicle, counts it as it crosses a line, and places it in one of three lane zones. A Random Forest labels traffic density and an Isolation Forest flags unusual patterns. FastAPI serves the video stream and the analytics to a React dashboard, packaged in Docker and hosted on Render.

Speed is pixel movement, not calibrated km/h. Lanes are three equal bands. The models have no accuracy figures yet, and the README says so.

Python, YOLOv8, ByteTrack, OpenCV, scikit-learn, FastAPI, React, Docker, Render

GOV.UK RAG assistant

An assistant that shows its sources, and says “I don’t know” when the pages don’t cover the question.

Ask about UK visas, right to work, employment rights or benefits and get a short answer with a link to the exact GOV.UK page it came from. It searches 129 indexed pages, and refuses instead of guessing when none of them fit.

Try the live demo Read the code

The demo runs on a free tier, so the first request after a quiet period can take about 30 seconds. Not legal advice.

  1. GateIf no indexed page is close enough to the question, stop and say “I don’t know”. No model call.
  2. Hybrid searchVector search and BM25 run side by side, merged with Reciprocal Rank Fusion.
  3. RerankA cross-encoder re-scores the top 20 and keeps the best 5.
  4. ContextChunks next to the best hits are added and merged by page, so each source is numbered once.
  5. AnswerGemini answers from the numbered sources only and cites them as [1], [2].
  6. CheckAn answer with no real citation is turned into a refusal.

Does search find the right page first?

Top-1 hit rate on 42 questions I wrote from random chunks and reviewed by hand.

  • Vector search only74%
  • BM25 only67%
  • Hybrid86%
  • Hybrid + rerank86%

Reranking ties hybrid on page-level hits but finds the exact source chunk more often: 98% against 93% in the top 5.

The same model family writes and judges the answers, which tends to be generous, so I checked samples by hand. The test set is small: treat the numbers as a regression test, not a benchmark.

What still fails

“Can I work full-time on a Graduate visa?” is refused, because the page says you can work in most jobs but never mentions hours, and the model won’t give a partial answer. Questions that ask for a full list of statutory pay types get an incomplete list. Both are in the write-up on purpose.

Four things it taught me

Boundaries lose answers.
The chunk that said “you can work in most jobs” was never retrieved because it sat just before the chunk that matched. Adding neighbouring chunks, and removing the repeated overlap, fixed it.
Citations must match what the user sees.
Numbering chunks but showing pages produced answers that cited [3] with no source [3]. Sources are now numbered per page and only cited pages are returned.
Prompt examples leak.
An example sentence in my prompt turned up at the end of unrelated answers. I removed it and added a test that keeps it out.
Strict refusals cost recall.
Telling the model to refuse unless the sources fully answer gave 100% refusal on out-of-scope questions, and also refused a question that was only partly covered. Fewer false refusals means a looser prompt, which trades against hallucination.
